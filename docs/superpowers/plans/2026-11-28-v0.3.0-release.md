# v0.3.0 Release Plan

**Goal:** publish the already-implemented `0.3.0` crate and GitHub release from the verified `feature-v0.3.0` branch.

**Execution:** native/inline, explicitly authorized by the maintainer. No further approval gate is needed for the release actions listed here.

## Tasks

1. Add a `Fixed` section to the `0.3.0` entry in `CHANGELOG.md` for the validation, watch, and stdin fixes; update the README prebuilt-archive link from `v0.2.0` to `v0.3.0`.
2. Run full verification: `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --all-features`, `cargo check --no-default-features --features mcp`, `cargo publish --dry-run`, and `git diff --check`.
3. Commit the release-notes/link changes on `feature-v0.3.0`.
4. Fast-forward `main` to `feature-v0.3.0` in its existing worktree, re-run the test suite on `main`, then push `main` to `origin`.
5. Create and push local tag `v0.3.0`; CI will build archives and publish the GitHub release.
6. Run `cargo publish` to crates.io.
7. Verify the GitHub release and crates.io version, and report the URLs. Do not force-push or rewrite history.
